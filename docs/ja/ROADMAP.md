# ロードマップ

> 英語版: [../ROADMAP.md](../ROADMAP.md)

方向性を示すものであり、確約ではありません — 各項目は準備が整った時点でリリースされます。優先度へのご意見は Issue と Discussions へお寄せください。

## 短期

- **チュートリアル用メディア** — ナレーション付き動画ウォークスルー(README のヒーロー GIF とドキュメント用スクリーンショットは作成済み。`docs/contributing/screenshots.md` 参照)
- **カメラキャプチャ連携** — 接続したカメラから直接採点します(キャプチャ API の下地は実装済みです)
- **判定 Webhook / PLC と連携しやすい軽量な結果出力**

## 検討中

- **エッジ書き出し** — バンク+圧縮検索をパッケージ化し、デバイス上での検査に対応します(モバイル / 組み込みが対象)
- **新規性ゲーティング** — 本当に新しいパッチだけを保存する教示時フィルタリングで、バンクの成長をさらに緩やかにします
- **マルチバンクルーティング** — ドロップは 1 回、製品に応じてバンクを自動選択します

## やらないこと

- クラウド学習 / ホスト型 SaaS — Cls-Studio はローカルファーストであり続けます
- ニューラルネットワーク学習の内蔵 — そこは兄弟プロジェクト seg-studio の担当領域です。Cls-Studio は意図的に学習しません
- エンタープライズ認証 (SSO/RBAC) — 代わりに前段へリバースプロキシを置いてください
