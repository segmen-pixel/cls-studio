# 機能カタログ

> 英語版: [../catalog.md](../catalog.md)

機能を 1 行ずつまとめたカタログです。詳細は [ユーザーガイド](user-guide.md) を参照してください。

## プロジェクトとバンク
- 複数プロジェクト、プロジェクト毎にメモリバンク 1 つ
- バンク毎の判定レシピ・書き出し・容量プラン
- プロジェクトカードに画像枚数とサムネイルをリアルタイム表示
- プロジェクト丸ごとの書き出し/読み込み(単一アーカイブ)

## バンク構築
- 複数ファイル一括インポート、PNG / JPEG / WebP / BMP / GIF / TIFF
- インポートは 1 回、ラベルは自由: エンコーダは 1 枚 1 回だけで、ラベル付けは保存済み特徴を使い回します
- ラベルセット: 同じ画像に対する別のラベル付けを、再エンコードなしで
- 3 層バンク: normal / critical(欠陥の種類別)/ negative
- 不良画像への欠陥見本の矩形マーク
- 全層に画像毎のパッチ上限(コアセット縮約。マーク済みの欠陥見本は必ず残ります)、追記のみのストレージ
- 画像単位の削除は該当行だけを正確に除去、サムネイルは可逆保存
- アトミックでクラッシュセーフな永続化、グループ毎のバッチ保存

## 分離度評価
- 教示済み全画像の leave-own-image-out 採点、結果はキャッシュ
- しきい値線付きの OK / NG スコア分布ヒストグラム
- k と α の自動調整、手動設定は上書きされません
- しきい値の提案、バンク毎の判定レシピ(要再確認フラグ付き)
- スコアで色付けされた PCA / コントラスト射影マップ

## 検査
- 複数画像キュー: 進捗・OK/NG 集計・処理中のリクエストごと中止するキャンセル(採点途中の結果は保存もログもされません)
- しきい値を基準点にした絶対スケールのダイバージングヒートマップ
- 欠陥ラベル別の帰属
- サーバー永続化された検査ログ(リロード後も復元、件数上限あり、削除可)
- TIFF の採点と表示用の自動変換
- タブ間で統一されたビューア操作(ズーム / パン / キー操作)

## パフォーマンスとメモリ
- バンク圧縮が標準で有効: int8 量子化 + IVF クラスタルーティング
- 常駐メモリ半減、バンクが育っても検索時間はほぼ一定([ベンチマーク](../../BENCHMARKS.md))
- 圧縮設定はアプリ内から変更可、ディスク上のデータは常にフル精度
- VRAM を考慮したチャンク処理(バンクが育っても OOM しません)、実測による最大バッチ判定

## ライフサイクル
- 時間を考慮した見本重み付け(重症度 × 鮮度)、ヒット追跡
- ドライランプレビュー付きの減衰メンテナンス
- バンクの書き出し/読み込みは `.clsbank.zip` 1 ファイル(判定レシピ同梱)
- プロジェクト丸ごとの書き出し/読み込みは `.clsproj.zip`(全バンク + 画像 + 検査ログ。読み込みは常に新しいプロジェクトとして作成)
- 育ちすぎたバンクのその場縮小(`scripts/reduce_bank.py`、まずドライラン、欠陥見本は保持)

## プラットフォーム
- Windows / macOS インストーラー、Docker compose、CPU のみモード
- ローカルファースト、LAN 公開はオプトイン+任意の共有シークレット認証(`X-API-Token` ヘッダー)
- 日英バイリンガル UI(ja / en)、色覚多様性に配慮した配色設計
- 合成デモ画像ジェネレーター(`scripts/make_demo_images.py`) — データなしで全ワークフローを試せます
- `/docs` で OpenAPI ドキュメントを提供する REST API
