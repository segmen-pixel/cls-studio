# ユーザーガイド

> 英語版: [../user-guide.md](../user-guide.md)

画面別リファレンスです。初回は [ハンドブック](handbook.md) か [はじめての実行](first-run-manual.md) の通し読みをおすすめします。

4 つのタブは作業順に並んでいます: **プロジェクト**で対象を選び、**バンク**で判定の土台となる記憶を作り、**学習**でその記憶が何を見分けられるかを確かめ、**検査**で使います。

## プロジェクト

- **プロジェクトカード**には画像枚数と、バンク先頭画像のサムネイルが表示されます。
- プロジェクトは、1 つのメモリバンク・それを作った画像・ラベルセット・検査ログを保持します。製品 × カメラ構成ごとに 1 つが目安です。
- 各カードの**書き出し**ボタンでプロジェクト丸ごとを `.clsproj.zip` 1 ファイルにダウンロードできます — バンク・画像・マーク・検査ログ入り。読み込み(`POST /api/v1/projects/import`)は常に新しいプロジェクトを作ります。詳細は [インポート/エクスポート](import_export.md)へ。
- プロジェクトを削除すると、バンク・キャプチャ・検査ログも削除されます。

## バンク

右側に番号付きの 3 ステップが縦に並びます。終わったステップには ✓ が付き、ラベルを 1 つでも変えるとステップ③の ✓ は自動的に外れます — ✓ は「ボタンを押した」ではなく「バンクが今のラベルと一致している」という意味です。

### ① バンク — 画像を入れる

- **+ 画像をインポート**は PNG / JPEG / WebP / BMP / GIF / TIFF を受け付けます。Web 非対応形式は表示用に可逆変換されます(採点は常に元のデコード画素)。
- インポートは**1 枚につき 1 回だけ**エンコーダを通し、パッチを保存します。ワークフローで時間がかかるのはここだけで、後からラベルを付け直しても繰り返しません。
- パネルには画像枚数・特徴行数・ディスク使用量・使用エンコーダが表示されます。
- **選択した画像を削除**は、その画像の行だけを正確に取り除きます。
- **書き出し / 読み込み**でバンクごとマシン間を移動できます — [インポート/エクスポート](import_export.md)。

どの画像にも 1 枚あたりのパッチ上限(`CLS_MAX_PATCHES_PER_IMAGE`、既定 2048)が適用され、各画像は最大その数の代表パッチを保存します。間引かれた不良画像は「どのパッチが残ったか」を記録しているので、欠陥マークは — 既存も今後も — 正しい行に着地します。

### ② ラベル — 1 枚ずつ判断する

- **ラベルセット**は現在の判断一式の名前です。**複製**すると同じ画像に対する別の判断一式を作れるので、厳しめと緩めのラベル付けを、再エンコードなしで並行して持てます。
- リストで行を選び、ボタンか `1` / `2` / `3` キーで層を割り当てます(`0` で解除)。リスト上のフィルタチップが層ごとの枚数を出し、1 つの層だけを表示できます。
  - **正常** — 良品。
  - **不良** — 不良品。**欠陥の種類**(`傷`、`焦げ` など)も付けると、バンクが一塊の「NG」ではなく名前の付いた欠陥を覚えます。既に使われている種類はボタンとして提示されます — これが `傷` と `傷 ` のような表記ゆれを防ぎます。
  - **誤検知抑制** — 異常に見えるが許容されるパターン。近いものはスコアが抑制されます。
- **欠陥をマーク**を押すと、選択中の不良画像に矩形を描けます。マークしたパッチが見本になり、α ブーストがスコアを引き寄せる先になります。マークは再編集可で、保存はその画像の前回マークを置き換えます。
- **グループを手動指定**は選択画像にロット名を付けます。学習タブでグループ分割を有効にすると、そのロットごと除外されます。

### ③ 組み立て — 判断をバンクに反映する

**ラベルを変えただけでは検査は変わりません。** バンクは**バンクを組み立てる**を押したときにストアから作られます。パネルには、今のバンクがラベルと一致しているかが表示されます。

## 学習

「このバンクは OK と NG を見分けられるか」に答えるタブです。右レール上部のトグルで、図を分離度評価と特徴分離マップの間で切り替えます。どちらも同じスイープの結果です。

### 分離度評価

- **▶ 評価を実行**でバンク内の全画像を、採点対象の画像を除外した上でバンクに対して採点します。結果はサーバー側にキャッシュされリロード後も復元。バンクや圧縮設定が変わるとキャッシュは自動で無効化されます。
- **AUROC** と OK / NG のヒストグラム、しきい値線。きれいに分離しない場合は重なっている画像がチップで一覧されます — クリックすると開きます。
- **メトリック / k / α** はスイープ完了時に自動調整(best k → その k での best α)。手動調整は上書きされません。
- **しきい値** — 提案を採用するか手動設定します。永続化は**検査**タブ側です: **判定設定を保存**でメトリック・k・α・しきい値がバンクに保存されます(書き出しに同梱される判定レシピの実体)。保存後にバンクが変わると「要再確認」の警告が付きます。
- **検証**は 1 枚あたりどこまで除外するかを決めます:
  - *1 画像だけ除外 (LOO)*(既定)は採点中の画像だけを外します。同一ロットの双子画像がバンクに残っていると楽観的に出ます。
  - *ファイル名の日時* / *ファイル名の接頭辞* は名前からグループを導き、グループごと除外します。ルールが見つけたグループ数と、分類できなかった枚数が表示されます — 何も分類できないルールは、黙って LOO に退化します。
  - *手動指定* はバンクタブで付けたグループ名を使います。

  切り替えると表示中の結果はクリアされます。グループ有効の実行は別の測定であり、かつサーバー側で意図的に評価キャッシュに入れない設計だからです。

### 特徴分離マップ

バンク特徴の 2 次元射影(PCA、不良画像があればコントラスト射影)。点はスコアで色付けされるので、外れ値やラベル間違いは違う集団に混ざった点として現れます。点をクリックするとその画像が開きます。

## 検査

- 画像をドロップすると(複数可)キューに入り、進捗・キャンセル・OK/NG 集計付きで順に採点されます。
- **ビューア**: ホイールズーム(1〜8 倍)、ドラッグ / Space+ドラッグ / 中ボタンでパン、ダブルクリックでフィット、↑/↓ で結果移動、`H` でヒートマップ切替、`Delete` で削除、`Esc` で選択解除 — 学習タブ・バンクタブと同じビューアです。
- **ヒートマップ**は絶対アンカー(OK 中央値=透明、しきい値=フルカラー)で、画像間で色が比較可能です。レシピ未保存時は画像内相対表示にフォールバックします。
- **アトリビューション**は欠陥の種類別の近さ(「傷にどれだけ似ているか」)を表示します。
- **検査ログ**はプロジェクト毎にサーバー保存(既定 200 件、古い順に削除)。リロード後も復元、個別削除可、クリアはサーバー側も消します。
- 行毎に往復時間、判定パネルにサーバー処理時間が表示されます。

## 設定

- **メモリバンク容量** — 小 / 中 / 大 と使用率バー。バーが示すのは正常層(容量プランが制限する対象)です。その下の行に、同じく常駐する不良・誤検知抑制のパッチ数と全層合計が表示されます。パッチ上限の導入前に大きく育ったバンクは `scripts/reduce_bank.py` でその場で縮小できます(既定はドライラン、欠陥マークはすべて保持)。
- **バンク圧縮** — int8 量子化と IVF ルーティングの切替、探索クラスタ数。既定で有効。検証したプロジェクトでは判定に影響しませんでした。変更すると評価キャッシュが無効化され(次回利用時に再計算)、保存済みレシピに要再確認が付きます。
- **ネットワーク** — LAN 公開のオプトイン(要再起動)、LAN URL とセキュリティ警告の表示。詳細は [デプロイ](deployment.md)。

**言語**(日本語 / English)と**テーマ**の切替はこのダイアログにはありません。どちらもヘッダー右側にあります。

## キーボードショートカット

| キー | 場所 | 動作 |
|---|---|---|
| `1` / `2` / `3` | バンクのリスト | 正常 / 不良 / 誤検知抑制 を割り当て |
| `0` | バンクのリスト | ラベルを解除 |
| ホイール | ビューア | ズーム(1〜8 倍) |
| Space+ドラッグ / 中ボタン | ビューア | パン |
| ダブルクリック | ビューア | フィット |
| ↑ / ↓ | リスト | 前後の画像へ |
| `H` | ビューア | ヒートマップ切替 |
| `Delete` | リスト | エントリ削除 |
| `Esc` | ビューア | 選択解除 |
