# エッジ書き出しフォーマット

> 英語版: [../edge_export.md](../edge_export.md)

`GET /bank/export/edge` は、このサーバーと通信する代わりに**デバイス上で** — スマートフォン、タブレット、組み込みボックスなど — 検査を実行するためのパッケージを書き出します。

`GET /bank/export` とは別物です。あちらは Cls-Studio 同士でバンクを移動するためのもので、fp16 特徴・教示に使った元画像・評価キャッシュを同梱し、数 GB になることもあります。こちらは画像の採点に必要なものだけを、量子化済みの状態で、画像を一切含めずに書き出します。

読み取りに必要なのは `.npy` パーサーと距離計算だけです。それ以外は何も要りません — torch も Python も不要です。

## レイアウト

zip はトップレベルに単一のディレクトリを持つので、展開するとバラのファイルではなく、ひとまとまりで取り込めるフォルダになります:

```
<bank-id>.clsedge.zip
  <bank-id>/
    manifest.json               the cls-studio contract (read this first)
    classes.json                host sidecar: class names and colours
    model_manifest.json         host sidecar: input size, class count, kind
    normal_codes.npy            int8    [N, D]
    normal_scale.npy            float32 [D]
    ivf_centroids.npy           float16 [K, D]     optional
    ivf_row_cluster.npy         int32   [N]        optional
    exemplars/<label>.npy       int8    [M, D]     optional, per defect label
    exemplars/<label>.scale.npy float32 [D]
```

実際の書き出し例として、272,384 行・768 次元のバンクの場合: int8 コードが 209 MB(fp16 なら 418 MB)、IVF セントロイドが 1.6 MB、行割り当てが 1.1 MB、zip 後で 188 MB です。

配列は `.npy` フォーマット version 1.0 で書かれます: dtype・shape・order を示す短い ASCII ヘッダーに続いて、リトルエンディアンの生データが並びます。30 行程度のリーダーで読み切れます。

## manifest.json

```json
{
  "format": "cls-studio-edge/1",
  "bank_id": "line3-connector",
  "encoder": {
    "model": "dinov2_vitb14",
    "dim": 768,
    "window": 518,
    "stride": 256,
    "patch": 14,
    "layers": null
  },
  "normal": {
    "rows": 271934,
    "dim": 768,
    "quantization": "int8-symmetric-per-dim",
    "dequantize": "value = code * scale[dim]"
  },
  "ivf": { "clusters": 1024, "nprobe": 8, "note": "..." },
  "exemplars": { "scratch": { "file": "scratch", "rows": 42 } },
  "verdict": { "k": 3, "threshold": 12.5, "metric": "l2" }
}
```

最も重要なのは `encoder` です。バンクの各行は、まさにこのエンコーダー・このウィンドウ・このパッチサイズで得たパッチ特徴です。**それ以外の方法で特徴を作るデバイスは、異なる 2 つの空間の点を比較していることになり**、距離は「単に不正確」ではなく「無意味」になります。ここに記述されたエンコーダーを再現できない場合、このパッケージは使えません — 何よりも先にこれを確認してください。

バンクに該当データがない場合、`ivf` と `exemplars` はありません(`null` / `{}`)。`verdict` は、そのバンクに判定レシピが保存されるまで `null` です。その状態のパッケージも有効で、デバイスに適用すべきしきい値がないというだけです。

## デバイス上での採点

1. `encoder` の記述どおりに入力をエンコードします。`[P, D]` 形状のパッチ特徴が得られます。
2. 各パッチについて、最も近い normal 行を `k` 個見つけ、その距離の平均を取ります。このパッチ毎の値が異常スコアで、画像スコアはパッチ全体での最大値です。
3. `verdict.threshold` があれば、それと比較します。

距離は int8 コードに対して直接計算できます — 行を `code * scale[dim]` で逆量子化するか、スケールをクエリ側に一度だけ畳み込んで量子化空間のまま比較します。通常は後者が高速です。

### IVF による探索の絞り込み

小さいバンクなら全行スキャンで十分です。`ivf` がある場合:

1. クエリパッチから `K` 個のセントロイドそれぞれへの距離を計算します。
2. 近い順に `nprobe` 個を取ります。
3. `ivf_row_cluster[row]` がその中に含まれる行だけに探索を限定します。

セントロイドはサーバー自身のインデックス由来なので、この手順に従うデバイスは、サーバーと同じ候補行に絞り込むことになります。`nprobe` は出発点として扱ってください: 上げれば候補集合が広がる代わりに時間がかかり、下げればその逆です。

### 欠陥見本 (exemplars)

各 `exemplars/<label>.npy` ブロックは、1 つの欠陥ラベルの代表行を、normal バンクと同じ方式で量子化して保持します。これが答えるのは「どの種類の欠陥に似ているか」であって、「これは欠陥か」ではありません — 後者に答えるのは normal バンクです。見本ブロックへの距離は類似のシグナルであり、判定ではありません。

## ホスト用サイドカー

`classes.json` と `model_manifest.json` は、この 2 つのファイル名を既に読み取る CoreML 検査アプリのために存在します。Cls-Studio を何も知らないホストでも、クラス名とオーバーレイ色は正しく扱え、理解できない配列は「一度も開かないファイル」として扱えます。

そのようなホストを書く場合に知っておくべきことが 2 つあります:

- `model_manifest.json` の `num_classes` はホストが**表示する**数 — normal と各欠陥ラベルの合計 — です。意図的にエンコーダーのチャンネル幅では*なく*してあり、そちらは `feature_dim` にあります。特徴マップをクラス logits として読むと意味のない結果になります。
- `postprocess` は `anomaly-knn` です。これは、採点が「チャンネルの argmax」ではなく「バンクへの距離」を意味することを示すフラグです。

すべての欠陥ラベルは、ラベル毎の色ではなく 1 つのオーバーレイ色(朱色、`#D55E00`)を共有します: 判定は二値であり、ラベルは何かが検出された後に*どの種類か*を伝えるだけだからです。紫ではなく朱色なのは、赤緑の色覚多様性の下でもオーバーレイの視認性を保つためです。

## サイズ

支配的なのは normal バンクです: int8 で `rows × dim` バイト、fp16 のおよそ半分です。270k 行・768 次元のバンクで約 200 MB — タブレットには余裕があり、スマートフォンには厳しいサイズです。選択肢を、試す価値のある順に:

- 教える枚数を減らすか、画像毎のパッチ上限を下げて、そもそもバンクの行数を減らします。
- より小さいエンコーダーを使います。BG バックボーンは DINOv2 を数 MB 級までのエンコーダーに蒸留したものです。`encoder` にそう明記され、デバイスがそれを再現できる限り、どのエンコーダーが特徴を作ったかをパッケージフォーマットは問いません。
- `dim` を減らします。全行が 1 単位ずつ支払う数字なので、削減効果(バイト数)が最も大きくなります。

## バージョニング

`format` は `cls-studio-edge/N` です。リーダーは、知らないメジャーバージョンを推測で読まずに拒否すべきです。同一バージョン内で新しい任意キーが追加されることがあります。認識できないものは無視してください。
