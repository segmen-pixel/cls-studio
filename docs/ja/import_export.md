# インポート / エクスポート

> 英語版: [../import_export.md](../import_export.md)

パッケージ形式は 2 種類、スコープも 2 種類です:

| | バンクパッケージ | プロジェクトパッケージ |
|---|---|---|
| ファイル | `.clsbank.zip` | `.clsproj.zip` |
| スコープ | 1 プロジェクトの **1 バンク**のみ | プロジェクトディレクトリ全体 |
| 含むもの | 特徴、マーク、レシピ、サムネイル | 全バンク+画像、マスク、検査ログ、クラス |
| 読み込むと | **開いている**プロジェクト内の新しいバンクになる | **新しいプロジェクト**になる |
| 典型的な用途 | 教示済みバンクを別ラインへ渡す | プロジェクト丸ごとの移動/バックアップ |

## プロジェクトパッケージ (`.clsproj.zip`)

プロジェクトディレクトリ配下のすべてを 1 つの zip に収めます: `project.json`、`classes.json`、(アクティブなものだけでなく)**すべての**メモリバンク、教示に使った元画像、マスク、検査ログです。

- **書き出し** — プロジェクトカード(プロジェクトタブ)のダウンロードボタン、または `GET /api/v1/projects/{id}/export` です。アーカイブは STORED (無圧縮) で書き出されるため(特徴配列はほとんど圧縮が効きません)、サイズはおおむねプロジェクトのディスク上のサイズになります — 実運用プロジェクトでは GB 級です。
- **読み込み** — `POST /api/v1/projects/import` (multipart の `archive`、任意で `name`) です。常に**新しい id を持つ新規プロジェクト**が作られます。既存のものは何も上書きされず、パッケージ内の id は新しい id に書き換えられます。判定レシピはバンク毎に同梱されるので、コピー先でも同一の検査ができます。
- アーカイブのアップロードには専用のサイズ上限 `CLS_MAX_ARCHIVE_MB` (既定 64 GB) があります — 画像 1 枚あたり 200 MB のアップロード上限とは別枠です(画像側の上限はパッケージには適用されません)。

## バンクパッケージ (`.clsbank.zip`)

バンクは自己完結した 1 つの zip として書き出されます — いわば Cls-Studio の「学習済みモデル」です。ただし、何も学習はされていません:

| 含まれるもの | |
|---|---|
| 特徴配列 | normal / critical / negative 層 |
| 見本メタデータ | 欠陥マーク、重症度、鮮度のサイドカー |
| マニフェスト | 画像毎の行インデックス、来歴名 |
| 判定レシピ | メトリック、k、α、しきい値 (`runtime_config.json`) |
| サムネイル | 教示画像の可逆コピー |
| 評価キャッシュ | 分離度評価の結果(派生データ、任意) |

書き出し/読み込みの両ボタンは、**バンク**タブのステップ①、インポートボタンの下に並んでいます:

- **書き出し** — アクティブなバンクを zip に書き出します。バンクに教示済みの良品画像が 1 枚以上あるまでは無効です。
- **読み込み** — `.clsbank.zip` を選ぶと、**現在開いているプロジェクト内の新しいバンク**として読み込まれ、アプリはそのバンクに切り替わります。プロジェクトの選択画面はなく、既存のバンクが上書きされることもありません。パッケージを専用のプロジェクトに入れたい場合は、先にそのプロジェクトを作成/オープンしてから読み込んでください。

読み込んだバンクは移行先のマシンでも同一の検査を行います。判定レシピが同梱されているので、カメラや光学系が異なる場合を除き、しきい値の取り直しは不要です。

補足:
- マシン固有の絶対パスは意図的にパッケージへ書き込みません(来歴として保持するのはファイル名だけです)。
- 圧縮インデックス (`ivf_index.npz`) は派生データで、読み込み後の初回利用時に再構築されます。そのためパッケージはデバイスや圧縮設定をまたいで可搬です。
- サムネイルは可逆保存なので、読み込んだパッケージからの再教示は元の教示とビット同一になります。

## 画像

**入力形式** — PNG、JPEG、WebP、BMP、GIF、TIFF。TIFF (ラインカメラ) はネイティブに採点されます。ブラウザでは表示できないため、UI 用には変換済みのプレビューが生成されます。Web 非対応形式は可逆 PNG サムネイルとして保存されます。

**検査結果** — プロジェクト毎に永続化されます(`projects/<id>/inspections/` 配下のログ+プレビュー+ヒートマップファイル)。個々のエントリは API (`/api/v1/inspections`) から取得できます。ログには上限があるため(`CLS_INSPECTION_LOG_CAP`、既定 200)、残しておきたいものは書き出してください。

## インスタンス丸ごとの移行

プロジェクト単体であれば、上記のプロジェクトパッケージがサポートされている手段です。**すべてを一度に**移すには、`CLS_PROJECTS_DIR` 全体を新しいマシンへコピーしてください([デプロイ — データ配置とバックアップ](deployment.md) を参照)。すべての状態がその中にあり、派生キャッシュは自動で再構築されます。
