# 手動 E2E チェックリスト (リリース前の通し確認)

> 英語版: [../e2e-checklist.md](../e2e-checklist.md)

中核フローは自動化された Playwright スイートがカバーしています。このリストはリリース前に人手で行う確認です。使い捨ての `CLS_PROJECTS_DIR` を使ってください。文言を確認する項目は日英両言語でチェックしてください。

## 起動とプロジェクト
- [ ] まっさらな状態で起動: サーバーが立ち上がり、UI が表示され、コンソールエラーがない
- [ ] プロジェクト作成 → 画像 0 枚のカードが表示される
- [ ] プロジェクト削除 → 一覧から消える。同じ名前での再作成ができる

## バンク
- [ ] 良品画像 3 枚をインポート → 未ラベルで表示される。リロード → 残っている
- [ ] 正常を付ける → ステップ②に ✓。**組み立て** → ステップ③に ✓、バンクの件数が増え、プロジェクトカードにサムネイルが表示される
- [ ] NG を 1 枚インポートし、新しい種類つきの不良を付ける → その種類が件数付きで表示される
- [ ] NG 画像を開き、**欠陥をマーク**で矩形を 2 つ描いて保存 → 再度開くと両方表示される
- [ ] ラベルを 1 つ変える → ステップ③の ✓ が外れる。もう一度組み立てると ✓ が戻る
- [ ] インポート済みの良品画像を 1 枚削除 → 件数が減る。分離度評価のキャッシュが無効化される
- [ ] TIFF をインポート → プレビューが表示され、インポートが成功する

## 学習
- [ ] スイープ実行 → 分布が表示される。k/α の自動調整が 1 回だけ走る
- [ ] **検証**をファイル名ルールに変更 → 表示中の結果がクリアされ、ルールのグループ数が表示され、次のスイープが `/bank/images/evaluate` に `group_mode` を送る(ネットワークタブで確認)
- [ ] 1 画像だけ除外に戻す → `group_` パラメータが送られず、キャッシュ済み結果が復元される
- [ ] スイープ中にタブ切り替え (Ctrl+→) → 進捗ダイアログと「中止」ボタンが画面に残り、キャンセルも機能する
- [ ] リロード → キャッシュ済みの結果が再採点なしで復元される
- [ ] 判定設定を保存(検査タブ) → リロード後も保持される
- [ ] さらに 1 枚教示 → レシピに「要再確認」の警告が表示される
- [ ] 射影マップが表示される。点のクリックで画像名が表示される

## 検査する
- [ ] 画像 3 枚をドロップ → キューが OK/NG 集計付きで処理される。キューの途中でキャンセルが機能する
- [ ] 画像を 1 枚だけドロップし、採点中にキャンセル → 行が消え、ボタンが「cancelling…」表示になり、リロードしても復活しない
- [ ] ヒートマップの `H` 切替、ズーム/パン/フィット、↑/↓ での移動
- [ ] リロード → サーバー側ログから結果が復元される。Delete で 1 件削除できる
- [ ] 判定がしきい値と一致する (明確な良品 1 枚と明確な NG 1 枚で確認)

## 設定
- [ ] 圧縮の切替がオン/オフ往復で反映される。採点時間の表示が設定状態を反映する
- [ ] 容量プランの変更が保持される。使用率バーが正しい
- [ ] NG を教示済みの状態で: バーの下にラベル付きパッチの行が全層合計とともに表示される
- [ ] LAN 公開のオプトインで再起動とトークンについて警告が出る。オプトアウトで元に戻る
- [ ] 言語切替 (ヘッダーのトグル): 4 つのタブすべてが両言語で表示される

## マルチクライアント / 障害系
- [ ] 2 つ目のブラウザでバンクを切り替え → 最初のタブが数秒以内に再バインドし、処理中の書き込みは明快な 409 で失敗する
- [ ] インポートの途中で API を kill → 再起動 → ストアは無傷、バンクは正常に読み込め、孤立データによる破損がない
- [ ] `CLS_API_TOKEN` を設定: 未認証の呼び出しは 401 になり、トークン付きの UI は動作する

## パッケージング
- [ ] バンクを書き出し → 新規プロジェクトを開く → 読み込み → パッケージがそこに新しいバンクとして入る。確認用画像のスコアが同一。判定レシピが引き継がれている
- [ ] プロジェクトを書き出し (カードのボタン) → 読み込み → バンクの行数が同一の別の新規プロジェクトができる。元のプロジェクトは変更されない
- [ ] `docker compose up --build` → 両コンテナが healthy になり、UI が使用できる
